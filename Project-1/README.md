# DecodeLabs Project 1 - Rule-Based AI Chatbot

## Project Goal

Create a simple rule-based chatbot that responds to predefined user inputs.

## Requirements Covered

- Handles greetings.
- Handles exit commands.
- Uses if-else logic for responses.
- Runs in a continuous loop.
- Demonstrates control flow and decision-making logic.

## How to Run

1. Install Python 3.
2. Open `chatbot.py` in VS Code, IDLE, PyCharm, or another Python editor.
3. Run the file.
4. Type messages in the terminal.
5. Type `bye`, `exit`, or `quit` to end the conversation.

## Example

You: hello

Bot: Hello! How can I help you?

You: who are you

Bot: I am a simple rule-based AI chatbot.

You: bye

Bot: Goodbye! Have a great day!

## Technology

- Python 3
- Conditional statements (`if`, `elif`, `else`)
- `while` loop
- String input processing

## Note

This is a rule-based chatbot. It does not use machine learning or a trained language model.
