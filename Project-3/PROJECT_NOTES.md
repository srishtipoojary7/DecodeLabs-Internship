# Project explanation

## Goal
Create a simple recommendation system based on user preferences.

## Input
The user enters interests or choices such as: `artificial intelligence, machine learning, python`

## Matching logic
The program converts text into TF-IDF vectors and calculates cosine similarity between the user's preference vector and each item's description.

## Output
Items are sorted from highest to lowest similarity and the top 5 are displayed.

## Main concepts
- User preference input
- TF-IDF vectorization
- Similarity matching
- Cosine similarity
- Ranking recommendations
