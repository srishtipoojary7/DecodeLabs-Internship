# AI Recommendation Logic - DecodeLabs Project 3

This project implements the requirements from Project 3:
1. Take user input (choices/interests)
2. Match preferences using similarity logic
3. Display recommended items

## Run
Install Python 3.9+.

```bash
pip install -r requirements.txt
python recommendation_system.py
```

The program uses TF-IDF vectors and cosine similarity to compare the user's interests with item descriptions. No external API is required.
